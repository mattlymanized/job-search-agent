# Proof Points

Interview prep draws from this file and nothing else. If a claim is not here, it does not get used. Add a claim only when you can point at where the number came from.

## How to write an entry

Each entry has the claim, the number, where the number came from, what it measures exactly, and the honest limits. Write the limits down now, because an interviewer will find them in about two follow-up questions.

```
### <Claim in one plain sentence>
- Number: <the figure and its time window>
- Source: <report, dashboard, export or document the number came from>
- Measures: <the exact definition, for example "cost per unit, not total cost">
- Limits: <what it does not show, for example "covers one region only" or "a vendor ran the day-to-day work; I owned the strategy and the measurement">
- Safe phrasing: <one sentence you would say out loud>
```
